# Conventions for Shizima Gits

## Branch naming

`type`/`#issueNb`-`description`

types:

- `feat`
- `fix`
- `doc`
- `ci`

## Commit message

`type`:`verb/description`

## PR

Names:

`#issueNb`-`description`

At least one issue must be linked to the PR.

And PR should be review by one person before merging.

## Issues

Names:

`Quick and clear description`

Add labels.
